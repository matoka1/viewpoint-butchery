# Viewpoint Butchery & Restaurant POS

A complete Point of Sale system for butchery and restaurant management.

## Features
- 🔐 Role-based authentication (Admin, Cashier, Butcher, Kitchen)
- 📊 Admin dashboard with sales analytics
- 💳 Cashier POS with M-Pesa & Cash payments
- 🥩 Butcher/Kitchen order management
- 📱 Mobile responsive

## Tech Stack
- HTML, CSS, JavaScript
- Supabase (PostgreSQL + Auth)
- Chart.js for analytics

## Setup
1. Run the SQL schema in Supabase SQL Editor
2. Open `login.html` in your browser
